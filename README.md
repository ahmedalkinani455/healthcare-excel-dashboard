# Healthcare Patient Dashboard (Excel)

An interactive Excel dashboard built on a 55,000+ patient healthcare dataset.

## Features
- KPI (Key Performance Index) summary cards (total patients, average billing, emergency percentage)
- Interactive slicers for gender, age, condition, medication
- Charts: monthly admissions, disease by age bracket, blood type split
- Key findings from the data

### Tools Used
- Microsoft Excel
- Kaggle to find the dataset: https://www.kaggle.com/datasets/prasad22/healthcare-dataset/data
